# Anchor Details artwork

The twelve category hero backgrounds in `categories/` were generated for the Anchor 2.0 Details screen. File names are deterministic: `<category>-details[-palette].jpg` (JPEG q85; PNG originals archived outside the repo). They contain environmental artwork only; the native screen renders the Anchor glyph, intention, controls, and data over them.

The generation prompt for each asset specified a portrait handmade editorial landscape with etched pencil and ink detail, soft watercolor, paper grain, open central space for native content, the category's tonal color family, and no text, glyph, UI, photorealism, 3D, or mystical imagery. Subjects: Desire mountain valley; Health botanical lake; Career road to city; Relationships garden paths; Creativity sunlit terraces; Spirituality mountain lake; Abundance orchard; Family homes and gardens; Learning path and architecture; Adventure coastal pass; Focus forest clearing; Custom open hills.

The Details screen reuses `src/assets/practice/today/{focus,deep-prime,visualize,release}.jpg` for the Today and Release artwork. It uses persisted Vision image URLs when present. No Vision or Chart artwork is fabricated for missing user data.

No category hero asset is missing.
