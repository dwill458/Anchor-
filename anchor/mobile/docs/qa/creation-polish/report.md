# Creation flow polish — 2026-10-04

Scope: the active `AnchorCreationFlow` screen and its existing scene/controller. Existing unrelated Home/details/export changes were preserved. No deployment or commit was performed.

1. **Forming:** enlarged the draw head with concentric light and a short path-following trail. Added a pale, high-contrast leading sweep to the existing material pass. Geometry, style treatments, duration, and backend generation remain unchanged. Copy follows the actual stages: “Drawing your line…” then “Applying your style…”. Reduced motion keeps its existing stationary material crossfade and starts with styling copy, because it does not animate a draw.
2. **Seal sound:** the ring-completion event now starts the flash, seal animation, and existing kit `seal` cue before invoking save/persistence. Previously sound fired before save, but the flash was scheduled after that work, allowing the image to lag behind the sound. Removed the separate wall-clock `anchorPulse` timer so a second sound cannot drift across motion modes. No press-start sound was added. The same event is the closest achievable synchronization through the current native audio/Reanimated APIs; sample/frame-exact device alignment has not been measured.
3. **Longer-wait styles:** removed “new — takes a little longer” from the style decision. The tag appeared for any non-default pick, so the forming caption follows the same condition (captured at commit): after the material reveal it reads “Forging your {Style} — this one takes a moment” (e.g. Porcelain). The default style keeps “Applying your style…”; the slow-request caption and retry behavior are unchanged. Actual user strokes still flow to every chip and the All Styles sheet.
4. **Landing:** retained the existing full-motion one-second rest after the 1.6-second coin sequence, extended reduced motion from 100 ms to the same one-second rest after its 400 ms crossfade, and added a light haptic immediately before the save-gated handoff. This intentionally uses the existing one-second pacing instead of shortening it to half a second. The kit seal is about 1.400 seconds long: the earliest reduced-motion departure is 1.400 seconds after the cue; full motion is 2.600 seconds. The existing save success/retry and Home arrival contracts remain intact.
5. **TODAY:** intentional per-Anchor recommendation behavior, not an automatic post-creation upgrade. `backend/src/services/v2/RecommendationService.ts` chooses Focus or Deep Prime for Anchors without Vision using a stable Anchor-ID hash; it also supports decay, Vision, and completion signals. Mobile maps Deep Prime to the Deep Focus presentation and uses the mode-specific saved durations. The account/Anchor-scoped cache and Home model prevent the prior Anchor’s recommendation from leaking when selection changes. A new regression exercises old Focus → new Deep Focus with their respective settings durations.
