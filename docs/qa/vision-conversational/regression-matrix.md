## Evidence limits

- Final validation reported by the integration owner: mobile 92 suites / 944 passed / 0 failed; backend 20 suites / 240 passed / 0 failed, with one database suite and two database integration tests skipped; migration harness 8 checks passed; mobile and backend TypeScript passed; final Hermes export passed. `test-summary.json` records these final results.
- The independent scorecard is 9.3/10 across seven selected states. The A1 fit issue is fixed; emulator swipe/Back interaction was verified. This is not a full all-viewport parity claim or device performance certification.
- Runtime PNGs under `runtime/` are mostly QA-lab/local-fixture renders. They do not prove an authenticated app journey, backend persistence, or physical-device behavior.
- Provider evidence is limited to the live-provider fixture runs and receipts in this folder; it is not end-to-end product acceptance. Flow 30's expansion pipeline passed a 1080×1920 center-preservation run, but the authenticated product Photo Fit journey remains unverified.
- Remaining validation: run the two skipped database integration tests against staging, perform authenticated end-to-end journeys, validate physical iOS permissions/haptics, and measure release-build frame pacing/60 FPS. Physical-device acceptance is not claimed.
- Flow 19 has automated isolation coverage, but the exact generated article quality is not live-validated.
